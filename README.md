# BinarySearch

A small .NET Core 3.1 console project demonstrating a binary search implementation and usage.

## Requirements

- .NET Core SDK 3.1
- Visual Studio 2022 (recommended) or any editor that supports .NET Core development

## Build and Run

### Using Visual Studio 2022:
1. Open the solution in Visual Studio.
2. Build the solution (Build ? Build Solution).
3. Set the console project as the startup project and run (F5 or Debug ? Start Debugging).

### Using the CLI:
```bash
# from the repository root
dotnet build
dotnet run --project ./BinarySearch
```

## Usage

The project is a console application. Run it and follow any prompts or view the sample output in the console. Typical output demonstrates searching a sorted array with a target value and returns the index or -1 if not found.

## Tests

If tests are added, run them with:
```bash
dotnet test
```
